# MRLN

Source for [mrln.online](https://mrln.online).

- **MRLN app** (`app.html`): a money and health tracker that runs in the browser and keeps everything on your device. No account, no server. Installable as an app (PWA), eight languages.
- **MRLN Studio** (`portfolio.html` and the demo pages): websites I build and host for local businesses.

Plain HTML, CSS and JavaScript, no build step. Published with GitHub Pages.

Built by Miradi Osefe, Aarhus.
